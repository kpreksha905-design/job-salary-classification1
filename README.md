# Job Salary Classification

A machine learning project using Python and Scikit-learn to classify a job into Low, Medium, or High salary categories.

## Algorithm
- Random Forest Classifier
- OneHotEncoder for categorical features
- Train/test split
- Classification report
- Confusion matrix

## Features
- Education
- Experience years
- Job level
- Industry
- Location type
- Skill count

## Target
- Low
- Medium
- High

## Installation

```bash
pip install -r requirements.txt
```

## Train the model

```bash
python train_model.py
```

## Make a prediction

```bash
python predict.py
```

## Run Web Frontend

```bash
streamlit run app.py
```

The included dataset is synthetic and intended for academic and educational use only.
